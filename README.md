# 🎓 Academic Report Generator

> A powerful, full-stack application designed to streamline the creation, management, and export of academic reports with high-fidelity document processing.

![Build Status](https://img.shields.io/badge/build-passing-brightgreen)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-ISC-lightgrey)

## ✨ Features

- **Rich Document Processing**: Generate and manipulate `.docx` and `.pdf` files dynamically using `docx` and `pdfkit`.
- **Advanced Image Handling**: High-performance image processing using `sharp` and `pdf-poppler`.
- **Modern Frontend**: Blazing fast UI powered by **React 19** and **Vite**.
- **Robust Backend API**: Secure and scalable REST API built on **Node.js** and **Express**.
- **Database Integration**: Seamless data persistence using **MySQL2**.
- **File Uploads**: Efficient multipart handling via `multer`.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- MySQL Server

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/AryaKSuryavanshi25/academic-report-generator.git
   cd academic-report-generator
   ```

2. **Backend Setup**
   ```bash
   cd backend
   npm install
   npm run dev
   ```

3. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
